The Cardano Memory LayerCardano メモリレイヤー

The Cardano Memory Layer is the front door to a single, durable record of the things this ecosystem produces and then tends to forget: how governance was decided, how the treasury moved, what Catalyst funded, and which projects existed. It exists to observe, measure, and archive — not to accuse, rank, or interpret.Cardano メモリレイヤーは、このエコシステムが生み出しながらも忘れ去りがちなもの——ガバナンスがどう決まり、トレジャリーがどう動き、Catalyst が何に資金を出し、どのプロジェクトが存在したか——を、単一かつ永続的な記録としてまとめた入口です。その目的は観測・計測・保存にあり、糾弾・順位付け・解釈ではありません。

Why memory mattersなぜメモリが重要か

Most of the Cardano ecosystem's record is perishable. Off-chain metadata URLs go dark. Funding platforms sunset and take their proposal history with them. Project sites disappear when a team disbands. Even on-chain governance — durable in principle — is hard to read after the fact without the surrounding context that explained what each action meant at the time it was decided.Cardano エコシステムの記録の多くは消えやすいものです。オフチェーンのメタデータ URL は到達不能になり、資金調達プラットフォームは終了とともに提案履歴を持ち去ります。チームが解散すればプロジェクトのサイトは消えます。原理的には永続するオンチェーンのガバナンスでさえ、各アクションが決定された当時に何を意味したかという周辺文脈なしには、後から読み解くのが困難です。

A memory layer treats that record as worth keeping for its own sake. The principle throughout is narrow and deliberate: capture what is verifiable, attach where it came from, and never overwrite it. Every value carries provenance — who said it, where it came from, when, and what archived evidence supports it. Nothing here is a score, a judgment, or a prediction. The record is the product.メモリレイヤーは、その記録それ自体に保存する価値があるものとして扱います。一貫する原則は狭く、かつ意図的です——検証可能なものを取得し、その出所を付し、決して上書きしないこと。各値には来歴(誰が・どこから・いつ・どの保存証拠に基づくか)が付随します。ここにはスコアも判断も予測もありません。記録そのものが成果物です。

How the record is structured記録の構成について ▾
The Memory Layer is composed of four records, described below. Each says what it is, why it is preserved, and where it lives — both the underlying archive and the live view on this site. Nothing here is a score, a judgment, or a prediction; every value carries provenance — who said it, where it came from, when, and what archived evidence supports it.メモリレイヤーは以下の4つの記録から成ります。各記録について、それが何であるか、なぜ保存されるか、どこに存在するか(基盤となるアーカイブと本サイト上のライブ表示の双方)を記します。ここにはスコアも判断も予測もありません。各値には来歴(誰が・どこから・いつ・どの保存証拠に基づくか)が付随します。

Governance Memoryガバナンスメモリ

What it is. The observatory's on-chain governance record: registered DReps and their delegated voting weight over time, every governance action recorded on-chain, and the per-action DRep vote tally. Voting weight is sampled in daily snapshots; actions and votes are read directly from the chain.概要。 オブザバトリーのオンチェーン・ガバナンス記録です。登録済み DRep と、時系列で委任された投票権、オンチェーンに記録された全ガバナンスアクション、アクション単位の DRep 投票集計を含みます。投票権は日次スナップショットで取得し、アクションと投票はチェーンから直接読み取ります。

Why it is preserved. Governance is durable on-chain but illegible without context. Preserving the daily series of voting weight, the action timeline, and the vote tallies makes it possible to reconstruct what the governance state actually was on any given day — facts, not interpretations of approval or rejection.保存する理由。 ガバナンスはオンチェーンでは永続しますが、文脈なしには読み解けません。投票権の日次系列、アクションのタイムライン、投票集計を保存することで、任意の日のガバナンス状態を事実として再構成できます。承認や否決の解釈ではありません。

Where it lives:所在:
  • Observatory — top DReps by voting weightオブザバトリー — 投票権上位 DRep
  • Governance actions indexガバナンスアクション一覧
  • Per-DRep page (vote history + 90-day chart)DRep 個別ページ(投票履歴 + 90日チャート)

Treasury Memoryトレジャリーメモリ

What it is. The FLOW-5 treasury observability record: the Cardano treasury balance per epoch, alongside reserves and total supply, and the history of treasury withdrawals. Lovelace amounts are reported in ADA; no figure is editorialised.概要。 FLOW-5 のトレジャリー可観測性記録です。エポックごとの Cardano トレジャリー残高を、準備金 (reserves) と総供給量とともに示し、トレジャリー引き出しの履歴を含みます。lovelace は ADA で表示し、いかなる数値にも編集的解釈を加えません。

Why it is preserved. The treasury is the ecosystem's shared balance sheet. A per-epoch series, kept over the full history, lets anyone see how the balance changed and when withdrawals occurred, without depending on a single point-in-time view that is gone by the next epoch.保存する理由。 トレジャリーはエコシステムの共有貸借対照表です。全履歴にわたるエポック単位の系列を保持することで、残高がどう変化し、いつ引き出しが行われたかを、次のエポックには消えてしまう単一時点の表示に依存せずに、誰もが確認できます。

Where it lives:所在:
  • Treasury — balance over epochs + withdrawalsトレジャリー — エポック別残高 + 引き出し

Catalyst MemoryCatalyst メモリ

What it is. The Catalyst preservation archive: a provenance-stamped capture of Project Catalyst's record — funds, proposals, milestones, and the platforms that hosted them — organised by source, with each source tagged by an authority class and, where applicable, a Wayback snapshot and content hash.概要。 Catalyst 保存アーカイブです。Project Catalyst の記録——ファンド、提案、マイルストーン、それらを掲載したプラットフォーム——を来歴付きで取得したもので、出典ごとに整理され、各出典には権威クラスが、該当する場合は Wayback スナップショットとコンテンツハッシュが付与されます。

Why it is preserved. Catalyst's history lives on platforms that are sunsetting; IdeaScale in particular is captured only via the Wayback Machine because the live platform is going away. Archiving it now, with verifiable provenance, keeps a record that would otherwise become unrecoverable.保存する理由。 Catalyst の履歴は終了しつつあるプラットフォーム上に存在します。特に IdeaScale は、ライブ環境が失われるため Wayback Machine 経由でのみ取得されます。検証可能な来歴とともに今アーカイブすることで、さもなければ回復不能になる記録を保ちます。

Where it lives:所在:
  • Catalyst — preservation status + fund coverageCatalyst — 保存状況 + ファンド網羅状況
  • cardano-catalyst-archive (source archive)cardano-catalyst-archive(基盤アーカイブ)

Project Memoryプロジェクトメモリ

What it is. An event-sourced, provenance-bearing, read-only record of Cardano projects and the ecosystem taxonomy that classifies them. The state is reconstructed from an append-only event log seeded from the preservation archive; nothing is overwritten or deleted, and every project and category value carries its source and authority class.概要。 Cardano のプロジェクトと、それらを分類するエコシステム分類体系の、イベントソース型・来歴付き・読み取り専用の記録です。状態は、保存アーカイブから種を得た追記専用イベントログから再構成されます。上書き・削除は行わず、各プロジェクトとカテゴリの値には出典と権威クラスが付随します。

Why it is preserved. Project directories disappear and defunct teams vanish from the live web. Keeping a project's metadata as an immutable, evidence-backed record — including the fact that a project once existed and is now defunct — preserves ecosystem history that no live directory has an incentive to retain.保存する理由。 プロジェクトディレクトリは消え、停止したチームはライブ Web から姿を消します。プロジェクトのメタデータを不変かつ証拠付きの記録として——あるプロジェクトがかつて存在し現在は停止しているという事実を含めて——保持することで、どのライブディレクトリも維持する動機を持たないエコシステムの歴史を保存します。

Where it lives:所在:

  • Ecosystem — category taxonomyエコシステム — カテゴリ分類体系
  • Project History Explorer — append-only provenance trailプロジェクト履歴エクスプローラー — 追記専用の来歴軌跡
  • Category Explorer — counts & enrichment coverageカテゴリ エクスプローラー — 件数と充実カバレッジ
  • Memory Heat Map — where memory is rich vs thinメモリ ヒートマップ — メモリの濃淡
  • cardano-project-memory-archive (source archive)cardano-project-memory-archive(基盤アーカイブ)

All of it is queryableすべてが照会可能

Every record above is served by the same read-only Cardano Data Layer API. The endpoints behind these pages — governance, treasury, the Catalyst archive, projects, and the category taxonomy — are all public, send Access-Control-Allow-Origin: *, and return a _quality provenance block with each response. See the API documentation for the full endpoint list and response shapes.上記のすべての記録は、同一の読み取り専用 Cardano Data Layer API から配信されます。これらのページの背後にあるエンドポイント——ガバナンス、トレジャリー、Catalyst アーカイブ、プロジェクト、カテゴリ分類体系——はすべて公開されており、Access-Control-Allow-Origin: * を送出し、各レスポンスに _quality 来歴ブロックを返します。エンドポイントの全一覧とレスポンス形式は API ドキュメントを参照してください。
