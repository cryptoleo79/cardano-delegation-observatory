## Thread

**1/**
Cardano needs observability you can trust. So we built one — and made it free,
keyless, open, and bilingual (EN/日本語).
Every value carries its own provenance. Nothing is scored, ranked by opinion, or
guessed.
👉 observatory.asy.life

**2/**
Governance, live: the Top-30 DReps by voting weight, with daily voting-weight and
delegator deltas (▲/▼), and a change feed answering "what changed today / this
week" — movement only, no inference of intent.

**3/**
Tokens & market: rankings by **circulating** market cap, real DEX liquidity, and
24h volume across ~1,048 verified tokens. Mint-cap artifacts are guarded against;
where a figure isn't real, we show null — not a guess.

**4/**
Project Memory: **847** projects across **74** categories, **715** with sourced
website / GitHub / docs / whitepaper links — each backed by a Wayback capture +
SHA-256. An event-sourced, tamper-evident record, not a snapshot.

**5/**
Preservation: the Catalyst archive is **15/15** funds, captured with
chain-of-custody before they can disappear. Treasury: **429** epochs of history.

**6/**
The foundation is a read-only Data Layer API — **37** routes, no key, open CORS —
and every response carries a `_quality` block: source, authority class (A–E),
confidence, and provenance.
api.asy.life

**7/**
Honesty is a feature. Coverage is stated explicitly; unknowns return null with a
note; freshness is public on a live heartbeat page (Fresh/Warning/Stale per
pipeline). We'd rather show a gap than fake a number.

**8/**
What makes it hard to copy: provenance on every value, an event-sourced memory,
preservation archives with custody, and one integrated layer spanning market +
projects + governance + treasury + Catalyst — free and open.
